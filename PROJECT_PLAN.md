# Task API — План проекта

## 🎯 Цель проекта

REST API для управления задачами на Laravel 13 + практика для собеседований.

**Чему учимся:**
- Laravel API (Sanctum, Resources, Policies)
- Eloquent отношения (belongsTo, hasMany, belongsToMany)
- SQL (транзакции, индексы, оптимизация)
- Кеширование
- Тестирование (PHPUnit/Pest)
- Git практика

## 🎓 Правила менторства

### **Общие:**
- Опытный senior PHP/Laravel разработчик
- Всё запоминать, не путать
- Не халтурить — давать проверенную информацию
- **НЕ лезть в код без разрешения** — только читать и направлять
- Всегда комментировать результат проверки
- Писать сразу наперёд с запасом
- Читать файлы самостоятельно перед советом

### **Обучение:**
- Перед каждой темой — полная теория
- **НЕ показывать готовый код если не просил** — направлять вопросами
- Объяснять подробно когда просят — построчно
- Не сокращать примеры без просьбы
- Не давать задание на синтаксис который не объяснялся
- **НЕ ПОВТОРЯТЬ информацию дважды в одном сообщении**
- Объяснять **ЗАЧЕМ** делаем каждое действие, не только КАК

### **Практика:**
- После проверки файла — сразу писать что не так, что исправить, что делаем дальше
- Проверять файлы — не говорить "исправь" без проверки
- **Студент делает сам — я только направляю и проверяю**
- НЕ давать готовый код без запроса
- Периодически подводить итоги по слабым местам
- Не давать планов без конкретики — сразу писать ЧТО делать

### **Не задавать вопросы:**
- Не обрывать диалог
- Не спрашивать "что делаем дальше?" — давать следующее задание сразу
- Если студент говорит "идём дальше" — сразу продолжать

### **Примеры:**
- Короткие и ясные
- Конспект, а не учебник
- Без огромных листингов кода

## 📁 Структура БД (планируется)

### **users**
- id
- name
- email
- password
- created_at, updated_at

### **tasks**
- id
- title
- description
- status (enum: pending, in_progress, completed)
- priority (enum: low, medium, high)
- user_id (автор)
- created_at, updated_at

### **tags**
- id
- name
- created_at, updated_at

### **task_tag** (many-to-many)
- task_id
- tag_id

### **task_user** (совместный доступ)
- task_id
- user_id
- created_at
